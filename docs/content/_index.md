# herobi

**herobi** は、ディレクトリ内の構成を素早く把握するためのRust製CLIツールです。

ファイルやディレクトリを一覧表示するだけでなく、ファイルの種類ごとの分類、ディレクトリサイズの表示、ディレクトリ全体のサマリー表示を行うことで、ディレクトリ構成を分かりやすく確認できます。

## Features

- ファイル・ディレクトリの一覧表示
- ファイルを種類ごとに分類して表示
- ディレクトリごとの使用容量を表示
- ファイル数・ディレクトリ数・合計容量のサマリー表示
- シェル補完（Bash / Zsh / Fish / PowerShell）に対応

## Usage

```text
herobi [OPTIONS] [PATH]
